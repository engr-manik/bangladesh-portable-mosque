# Bangladesh Portable Mosque — Website Starter

এই ফোল্ডারে একটি responsive, বাংলা/ইংরেজি charity initiative website তৈরি করা হয়েছে। এটি HTML, CSS ও JavaScript দিয়ে বানানো; আলাদা server বা database প্রয়োজন নেই।

## ১) নিজের কম্পিউটারে চালু করুন (Windows)

1. ZIP ফাইল Extract করুন।
2. `bangladesh_portable_mosque_website` ফোল্ডার খুলুন।
3. `index.html` ফাইলে double-click করুন।
4. Chrome/Edge-এ ওয়েবসাইট খুলবে।
5. মোবাইল ভিউ পরীক্ষা করতে Chrome-এ `F12` চাপুন, তারপর device toolbar আইকনে ক্লিক করুন।

## ২) প্রকাশের আগে অবশ্যই পরিবর্তন করুন

1. `script.js` খুলুন।
2. `YOUR-OFFICIAL-EMAIL@example.com`-এর জায়গায় উদ্যোগের অফিসিয়াল ইমেইল দিন।
3. `index.html`-এ `Replace with your official email` লেখা অংশটি বাস্তব যোগাযোগের তথ্য দিয়ে বদলান।
4. অফিসিয়াল ফোন, WhatsApp, Facebook page, নিবন্ধন/আইনি পরিচয় এবং অনুদানের যাচাইকৃত তথ্য প্রস্তুত হলে তবেই প্রকাশ করুন।
5. এখনকার Donation অংশটি যোগাযোগের আহ্বান মাত্র—কোনো টাকা গ্রহণ বা পেমেন্ট প্রসেস করে না। যাচাইকৃত ব্যাংক/MFS হিসাব ও প্রয়োজনীয় অনুমোদন ছাড়া পেমেন্ট নম্বর যোগ করবেন না।
6. ছবির/নকশার অংশটি concept illustration; বাস্তব গাড়ি বা চালু সেবার ছবি হিসেবে ব্যবহার করবেন না।

## ৩) GitHub Pages-এ বিনামূল্যে প্রকাশ

আপনার GitHub account থাকলে:

1. GitHub-এ sign in করুন।
2. `New repository` ক্লিক করুন।
3. Repository name দিন `bangladesh-portable-mosque`।
4. Public নির্বাচন করে `Create repository` করুন।
5. এই ZIP-এর ভেতরের ফাইলগুলো extract করে repository-র মূল জায়গায় upload করুন। `index.html`, `styles.css`, `script.js` যেন সরাসরি root-এ থাকে।
6. `Commit changes` ক্লিক করুন।
7. Repository-র `Settings` → `Pages` খুলুন।
8. `Build and deployment` অংশে `Deploy from a branch` নির্বাচন করুন।
9. Branch হিসেবে `main` এবং folder হিসেবে `/ (root)` নির্বাচন করে `Save` করুন।
10. কয়েক মিনিট পর Pages অংশে দেওয়া website link খুলুন।

## ৪) গুরুত্বপূর্ণ সীমাবদ্ধতা ও পরবর্তী উন্নয়ন

- এই সংস্করণটি একটি public information / landing website।
- Volunteer form বর্তমানে আপনার email app-এ message তৈরি করে; server-এ তথ্য সংরক্ষণ করে না।
- Donation gateway, volunteer database, admin dashboard, analytics ও content management এখনো যুক্ত করা হয়নি।
- Donation/payment চালুর আগে প্রতিষ্ঠানের পরিচয়, অনুমোদন, হিসাবের মালিকানা, রসিদ ও স্বচ্ছতা নীতি যাচাই করুন।
- Google Fonts ব্যবহারের জন্য internet connection প্রয়োজন; internet না থাকলেও মূল layout চলবে।

## ৫) ফাইলের তালিকা

- `index.html` — সব website content
- `styles.css` — design ও responsive layout
- `script.js` — language toggle, mobile menu ও contact form
- `README-BN.md` — বাংলা নির্দেশিকা
